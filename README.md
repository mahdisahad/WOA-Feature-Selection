# WOA-Feature-Selection
Feature selection on high-dimensional medical datasets using a Binary Whale Optimization Algorithm (WOA). The project compares a classifier trained on all features against the same classifier trained only on the features selected by WOA, with a leakage-free evaluation pipeline.

Reference:
Mirjalili, S., & Lewis, A. (2016). The Whale Optimization Algorithm. Advances in Engineering Software, 95, 51–67.
